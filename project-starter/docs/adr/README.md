# Architecture decision records

One file per decision that would be expensive to reverse: `0001-short-title.md`, numbered in order.
Written with `mattpocock-skills:domain-modeling` when a decision is made during grilling or a spec.

Each record has: **Context** (what forced the decision), **Decision**, **Consequences** (what gets easier, what gets harder), and the date.
A decision is replaced by a new record that links back to it, never by editing the old one.
