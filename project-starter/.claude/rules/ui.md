# UI

- Follow `DESIGN.md`: its tokens, font and rules. If it is still the empty stub, agree a direction with the owner (via `impeccable`) before building screens.
- Use the existing component library and tokens; no new colours or one-off styles.
- Every screen needs empty, loading and error states and must work at phone width.
- Before saying done, open the page in a browser at desktop and phone width and look at it.
