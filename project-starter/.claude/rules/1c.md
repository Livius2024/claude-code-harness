# 1C:Enterprise code

- Keep the configuration's existing language for identifiers (usually Russian) and its naming style; don't mix in English names.
- Never change a typical (vendor) object in place when an extension (`расширение`) can do it.
- Chart-of-accounts codes, subconto types, tax rates and report lines come from the owner or the legal source, never from memory. Ask when unsure.
- Code that writes documents or postings needs a check on a copy of the infobase, never on the production base.
